# 산들 랜딩 페이지

첫 화면은 집에서 소파에 앉아 산들 앱을 확인하는 여행자의 3D 장면입니다. 옆에 캐리어가 놓여 있고, 스크롤하면 카메라가 사람과 휴대폰 쪽으로 천천히 다가갑니다. 하늘색·흰색·파란색 톤을 유지했습니다. 휴대폰은 뒷면이 보이도록 연출했습니다.

## 사용 기술

- HTML5, CSS3, JavaScript ES Modules
- Vite: 로컬 개발 서버 및 프로덕션 빌드
- Three.js: 3D 모델, 조명, 카메라와 애니메이션
- IntersectionObserver, requestAnimationFrame: 화면 진입 감지와 스크롤 연출
- Pretendard: 웹 폰트

## 실행

```sh
npm install
npm run dev
npm run build
```

로컬 주소: http://127.0.0.1:5173/
배포하지 않았습니다.


## 기능 소개 섹션

운항정보, 공항 혼잡도, 주차 안내를 일반 스크롤 순서대로 소개합니다. 중복 제목과 선택 탭을 없애고, 각 기능의 큰 제목·짧은 설명·620px 높이의 3D 비주얼을 배치했습니다. 운항정보에는 탑승권, 혼잡도에는 상태 표시, 주차에는 빈자리 수를 함께 보여줍니다. 첫 화면의 소파 장면과 헤더는 유지했습니다.

3D는 Three.js 실시간 렌더링입니다. 화면 안에 있는 장면만 재생하고, 각 캔버스의 그리기 영역을 제한하여 다른 섹션과 겹치지 않게 했습니다. 모션 감소 설정에서는 정지 장면을 표시합니다. 표시 수치와 항공편은 소개용 고정 데이터이며 실시간 API가 아닙니다.

AI 기능과 앱 다운로드는 출시 준비 안내를 표시합니다. AI 상세 소개는 추후 추가합니다.
